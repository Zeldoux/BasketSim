# BasketSim
BasketSim is a Basketball game simulation using c# 
# BasketSim Manager

Simulation de gestion de basket-ball développée en C#.
Le joueur gère une équipe, ses rotations et ses tactiques.


## Stack technique
- C# / .NET 9
- xUnit (tests)
- Blazor WebAssembly (prévu Projet 2)

## Structure de la solution
- `BasketSim.Core` — moteur de simulation, logique pure
- `BasketSim.Console` — interface console pour tester le moteur
- `BasketSim.Tests` — tests unitaires du moteur
